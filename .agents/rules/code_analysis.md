# Source Code Analysis Persistence Rule / ソースコード解析結果の永続化ルール

## 目的 (Purpose)
ソースコード全体の再解析によるトークン消費と処理コストを最小化するため、解析・修正によって得られた知識を `CODE_ANALYSIS.md` および `CODE_ANALYSIS_UI.md`（`.agents/references/` 配下）に永続化し、以後の開発作業で再利用する。

---

## 役割分担と対象ファイル (Scope Separation)

AI コーディングを開始する際、クォータ（トークン）を節約するため、**作業対象の領域に応じたファイルのみを先立って読み込む**こと。

| 対象領域 | 参照・更新する解析ファイル | 内容とスコープ |
| :--- | :--- | :--- |
| **AHK コアエンジン** (`src/*.ahk`) | [`CODE_ANALYSIS.md`](../references/CODE_ANALYSIS.md) | 全体アーキテクチャ、ファイル横断連携、状態機械、HoldMode 0〜9 の判定決定表、レイヤー配列バインディング。**※UI関連は除く** |
| **Web 設定エディタ UI** (`src/ui/*`) | [`CODE_ANALYSIS_UI.md`](../references/CODE_ANALYSIS_UI.md) | Web UI アーキテクチャ、`IniDocument` パーサー仕様、DOM/イベント連携、`[LayerBinding]` 同期ロジック |
| **用語・規約・日英対照** (共通) | [`GLOSSARY.md`](../references/GLOSSARY.md) | ドメイン用語定義、日英対照表、ホールドモード一覧、コーディング不変条件 |

---

## 最重要原則 (Core Cardinal Rules)
1. **作業領域に応じた参照義務 (Domain-Specific Prior Reference)**:
   - ソースコードを一から再解析する前に、AHK ロジック修正なら `CODE_ANALYSIS.md`、UI 修正なら `CODE_ANALYSIS_UI.md` を**必ず先に参照**すること。
   - 関係のない側の解析ファイルは読み込まず、コンテキスト消費を抑制すること。
2. **コンパクトで再利用可能な知識の維持 (Token-Efficient Knowledge)**:
   - 後続の AI エージェントがソースコード全体を読まずに作業できるよう、決定表や箇条書きでコンパクトに記録すること。
3. **コスト最小化の追求 (Minimal Reading Cost)**:
   - 網羅性そのものを目的とせず、最小のトークン数で直結する情報を取得できる状態を維持すること。

---

## 基本ルール (Standard Rules)

### 1. 解析結果の記録と再利用
- ソースコードを解析した場合、その結果を対応するファイル (`CODE_ANALYSIS.md` または `CODE_ANALYSIS_UI.md`) に記録すること。
- ソースコードを修正した場合、影響を受けたファイルのみを更新すること。
- 既存の解析結果がある場合は、作業開始時に最初に読み取り、同じ内容を再解析しないこと。

### 2. 解析コストの最小化
- 解析ファイルを読むコストが、対象コードを一から解析するコストより確実に小さくなるように記述すること。
- コード全体を再解析せず、変更箇所とその依存関係を中心に差分解析すること。
- 自明なコード列挙や不要な文章記述は排除すること。

### 3. AI 最適化構造形式 (Compact Structured Format)
- Markdown 見出し、箇条書き、決定表 (Decision Tables)、Mermaid 状態遷移図を活用すること。
- ファイルパス、シンボル名、関数名、クラス名、依存関係、不変条件 (Invariants) を明確に記載すること。
- 同一情報の重複記載を避け、既存の項目をインプレースで更新すること。

### 4. 修正時の更新手順
1. 作業対象に応じた解析ファイル (`CODE_ANALYSIS.md` / `CODE_ANALYSIS_UI.md`) および `GLOSSARY.md` を確認する。
2. 既存情報を利用して、変更対象とその依存関係を特定する。
3. 必要な差分範囲だけソースコードを精査・解析・修正する。
4. テストや構文検証（`/validate`）を実施する。
5. 変更によって影響を受けた解析ファイルのみを更新する。
