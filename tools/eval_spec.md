1. 生体力学的な「弱点」の分離評価
   これまでは「弱い指＝一律でペナルティ」としていましたが、指の「筋力（持久力）」と「独立性（器用さ）」を完全に分けてスコア化しました。

   単純な直線距離ではなく、人間の関節の可動域に基づいた方向別の負荷を定義しました。

横方向（ラテラル）の制限: 指を横に開く動き（特に人差し指を中心列へ伸ばす動きや、小指の外側への伸展）は手首への負担が大きいため、縦移動よりも厳しいペナルティを課しています。

3. タイピングの「流れ」を捉える文脈評価
   単一のキーの押しやすさだけでなく、前後のキーとの組み合わせ（動的計画法を活用した文脈）を精緻に評価しています。

シザーズ（ハサミ打ち）: 中指が上段、薬指が下段など、隣り合う指が裂けるような負担の大きい動きを明確に減点します。

ロールと交互打鍵: 小指側から人差し指側へ滑らかに打ち込む「内向きロール（Inward Roll）」や「交互打鍵」など、人間にとって自然で高速な動きにはボーナス（コスト削減）を与えます。

# キー配列生体力学評価モデル仕様書 (Calculated Mode v3.0)

## 1. 概要と基本設計思想

本仕様書は、キーボードの物理的形状（ハードウェア特性）と、人間の手の解剖学的・生体力学的な制約（身体特性）をモデリングし、任意の論理配列が持つ「タイピングコスト（非効率性と疲労度）」を算出するための計算ロジックを定義するものです。

従来の直線距離ベースの評価から脱却し、以下の3点を統合的に評価します。

1. **物理形状の切り替え**：ロウスタッガード、オーソリニア、カラムスタッガードの座標空間定義。
2. **生体力学的パラメーターの分離**：指の「基礎筋力」と「独立性」の分離。
3. **運指文脈と異方性評価**：斜め移動における横方向の重み付けと、前後の打鍵文脈（SFB、シザーズ等）の評価。

---

## 2. 物理形状エミュレーションと座標変換

論理配列のキー位置を、3行×10列のグリッド座標 $(X_{grid}, Y_{grid})$ として定義します。

- X座標: 左端 $X_{grid} = 0$ 〜 右端 $X_{grid} = 9$
- Y座標: 上段 $Y_{grid} = 0$、中段 $Y_{grid} = 1$、下段 $Y_{grid} = 2$

対象とするキーボードの形状に応じて、以下の幾何学的変換を行い、物理座標 $(X_{phys}, Y_{phys})$ を算出します（単位：U）。

### 2-1. ロウスタッガード (Row Staggered)

標準的なキーボードの行ごとの横方向へのズレです。

- $Y_{phys} = Y_{grid}$
- $X_{phys} = X_{grid} + Offset_{row}[Y_{grid}]$

**各段のオフセット値:**

- 上段 ($Y_{grid} = 0$): $Offset_{row} = -0.25$
- 中段 ($Y_{grid} = 1$): $Offset_{row} = 0.0$
- 下段 ($Y_{grid} = 2$): $Offset_{row} = +0.5$

### 2-2. オーソリニア (Ortholinear)

格子状配列であり、ズレは存在しません。

- $X_{phys} = X_{grid}$
- $Y_{phys} = Y_{grid}$

### 2-3. カラムスタッガード (Column Staggered)

エルゴノミクスキーボードにみられる、列ごとの縦方向のズレです。

- $X_{phys} = X_{grid}$
- $Y_{phys} = Y_{grid} + Offset_{col}[X_{grid}]$

**各列の縦オフセット値（左右対称）:**

- 小指列 ($X_{grid} \in \{0, 9\}$): $+0.25$
- 薬指列 ($X_{grid} \in \{1, 8\}$): $+0.10$
- 中指列 ($X_{grid} \in \{2, 7\}$): $-0.15$
- 人差し指列 ($X_{grid} \in \{3, 4, 5, 6\}$): $0.00$

## 3. 静的コスト (Static Cost)

そのキー単体を押し下げる際に生じる「純粋な位置的な押しづらさと身体的負荷」を表します。以下の要素をすべて **乗算** して算出します。

$$C_{static} = W_{strength}[f] \times P_{row}[f][Y_{grid}] \times P_{lat}[f][X_{grid}] \times S_{static}$$

_(※スケール係数 $S_{static} = 10.0$)_

### 3-1. 指の基礎筋力ウェイト ($W_{strength}$)

指全体の筋肉量、最大発生トルク、持久力の限界を反映します。

- 人差し指 / 親指: **1.0**
- 中指: **1.1**
- 薬指: **1.3**
- 小指: **1.8** （最も非力で疲労が蓄積しやすい）

### 3-2. 指×段ペナルティ ($P_{row}$)

指の長さや、関節の屈曲・伸展の可動域に応じた段ごとのペナルティです。

| 担当指       | 上段 (伸展) | 中段 (ホーム) | 下段 (屈曲) |
| :----------- | :---------- | :------------ | :---------- |
| **人差し指** | 1.20        | 1.00          | 1.10        |
| **中指**     | 1.05        | 1.00          | 1.50        |
| **薬指**     | 1.20        | 1.00          | 1.40        |
| **小指**     | 1.50        | 1.00          | 1.20        |

### 3-3. ラテラルストレッチ・ペナルティ ($P_{lat}$)

ホーム列から横方向へ指を開く動きに対するペナルティです。

- **人差し指 内側拡張列**（G, Hなどの列）: 上段 **1.20** / 中段 **1.30** / 下段 **1.60**
- **小指 外側拡張列**（Pの右側など）: 一律 **1.25**
- **各指のホーム列**: 一律 **1.00**

## 4. 動的コスト (Dynamic Cost) と運指文脈評価

直前に打鍵したキーから現在のキーへの遷移に伴うコストです。

### 4-1. 異方性距離 ($D$)

関節構造上、「横方向の開き」は「縦の曲げ伸ばし」よりも筋骨格系に強いストレスをかけます。このため、X軸の移動距離に **1.5倍** の重みを課します。

$$D = \sqrt{(\Delta X \times 1.5)^2 + \Delta Y^2}$$
_(※ $\Delta X = X_{phys\_to} - X_{phys\_from}, \Delta Y = Y_{phys\_to} - Y_{phys\_from}$)_

### 4-2. 同一キー連続打鍵 (Double Tap)

直前と全く同じ物理キーを打つ場合、指の物理移動は発生しません。
この場合、静的コストを割引し、動的ペナルティは加算しません。
$$C_{total} = C_{static} \times 0.2$$

### 4-3. 基本移動コスト ($C_{move}$)

指を遠くまで飛ばす動きは指数関数的に疲労が蓄積するため、距離 $D$ を **1.2乗** して評価します。
$$C_{move} = D^{1.2} \times W_{strength}[f] \times S_{dynamic}$$
_(※スケール係数 $S_{dynamic} = 10.0$)_

### 4-4. 文脈ペナルティ ($P$)

嫌悪される特定の運指パターンに対するペナルティです。

1. **SFB (Same Finger Bigrams) ペナルティ**:
   同一指で異なるキーを連続打鍵する動き。移動コストに指の「独立性」を掛け合わせます。
   $$P_{SFB} = (B_{SFB} + C_{move}) \times W_{independence}[f]$$
   - ベースペナルティ ($B_{SFB}$): **+80.0**
   - 独立性ウェイト ($W_{independence}$): 人差し指・中指 = **1.0**, 薬指・小指 = **1.5**
2. **シザーズ (Scissors) ペナルティ [+25.0]**:
   同じ手で、隣接する指が逆方向（上段と下段）に引き裂かれる動き。
3. **行またぎ (Row Jump) ペナルティ [+15.0]**:
   同じ手で、ホーム段を経由せず上段⇔下段へ直接ジャンプする動き。
4. **リダイレクト (Redirects) ペナルティ [+10.0]**:
   同じ手で一方向へ流れた直後、人差し指を経由せずに方向転換する動き（例：小指→薬指→中指→薬指）。

### 4-5. 文脈ボーナス ($B$)

人間にとって自然で滑らかな運指に対する報酬（コスト減算）です。

1. **内向きロール (Inward Roll) [-5.0]**:
   同じ手で、外側（小指側）から内側（人差し指側）へと握り込むように流れる打鍵。
2. **外向きロール (Outward Roll) [-2.0]**:
   同じ手で、内側から外側へと開くように流れる打鍵。
3. **交互打鍵 (Alternation) [-3.0]**:
   左右の手が交互に切り替わる打鍵。
