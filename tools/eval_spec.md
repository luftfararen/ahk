# Calculatedモード 計算モデル仕様書 (Refined Ver.)

この文書は、キーボード配列評価スクリプトに実装されている生体力学に基づく評価モデル（`calculated` モード）の計算ロジックをまとめたものです。

人間の手の骨格・関節の動きの制約を数式化し、特に「指ごとの長さの違いによる曲げ/伸ばしの得意・不得意」**や**「横方向へのストレッチ（ラテラルストレッチ）に対する負荷」を精密に評価することで、より現実的な疲労感と打鍵コストを算出します。

---

## 1. 静的コスト (Static Cost)

「あるキー単体を打鍵する際にかかる基礎的な負荷」を計算します。
以下の要素をすべて**掛け合わせる（乗算）**ことで、キーの物理的配置と担当する指の解剖学的な相性をスコア化します。

静的コスト $C_{static}$ は以下の数式で計算されます：
$$C_{static} = W_f \times P_{row} \times P_{lat} \times S_{static}$$

- **$W_f$**: 指の基礎重み (Base Finger Weights)
- **$P_{row}$**: 指ごとの段ペナルティ (Row Penalties)
- **$P_{lat}$**: ラテラルストレッチ・ペナルティ (Lateral Stretch Penalty)
- **$S_{static}$**: 全体スケール係数 ($10.0$)

### 1-1. 指の基礎重み ($W_f$)

指の独立性や基礎筋力に基づく重みです。弱い指ほど高いコストが設定されます。（※値は後から調整可能）

- 小指 (Pinky): **1.3**
- 薬指 (Ring): **1.4**
- 中指 (Middle): **1.1**
- 人差し指 (Index): **1.0**

### 1-2. 指ごとの段ペナルティ ($P_{row}$)

指の長さや関節の構造により、「上段（伸ばす）」「下段（曲げ込む）」のどちらが得意かは指によって異なります。これを表現するため、一律の段ペナルティではなく**指×段のマトリクス**で係数を定義します。

_想定される特性の例（パラメータは調整可能）:_

- **中指**: 一番長いため、上段（伸ばし）は容易だが、下段（曲げ）は窮屈になりやすい。
- **小指**: 短いため、上段へ伸ばす動きは手全体を動かす必要があり重い。
- **人差し指**: 柔軟性が高く、上段・下段ともに比較的ペナルティが低い。

### 指ごとの段ペナルティ

| 指           | 上段 (Top: 伸ばし) | 中段 (Home) | 下段 (Bottom: 曲げ) | 生体力学的な根拠                                                                                       |
| ------------ | ------------------ | ----------- | ------------------- | ------------------------------------------------------------------------------------------------------ |
| **人差し指** | 1.4x               | 1.0x        | **1.2x**            | 手前に曲げる動きが得意。伸ばすよりも曲げる方が自然。                                                   |
| **中指**     | **1.1x**           | 1.0x        | 1.2x                | 指が最も長いため上段へは自然に届くが、下段へ曲げ込むのは非常に窮屈。                                   |
| **薬指**     | 1.4x               | 1.0x        | 1.8x                | 独立性が低くどちらも負担。中指につられて下段は特に打ちづらい。                                         |
| **小指**     | 2.0x               | 1.0x        | **2.5x**            | 指が短いため、上段へ伸ばすには手首や腕全体を前に押し出す必要があり高コスト。手前に曲げる方がまだマシ。 |

### 1-3. ラテラルストレッチ・ペナルティ ($P_{lat}$)

ホームポジション（担当列）から横方向（X軸方向）へ指を開く動きに対するペナルティです。
指の構造上、横に開く動きは手首や腕全体の力みにつながるため、伸ばす距離や指の特性に応じて加算されます。

**A. 中心列への内側ストレッチ (Inward Lateral Stretch)**
主に人差し指が担当する中央列（T, Y, G, H, B, Nなど）へのアプローチです。手首を内側に捻る・腕を動かす動きが加わるため、段の曲げ伸ばしペナルティにさらに乗算されます。

- **上段中心 (T, Y等): 1.4x**
- **中段中心 (G, H等): 1.2x**
- **下段中心 (B, N等): 1.1x**

**B. 外周列への外側ストレッチ (Outward Lateral Stretch)**
主に小指が通常の担当列よりさらに外側（Enter, Shift, 一部の記号など）へ伸ばす動きです。手首を外側に捻る必要があるためペナルティを与えます。

- **小指の外側伸ばし: 1.8x** （※上段/中段/下段で細分化することも可能）

## 2. 動的コスト (Dynamic Cost / Travel Cost)

「直前に打ったキーからの移動に伴う負荷」を計算します。特に、同じ指で異なるキーを連続して打つ（SFB: Same Finger Bigram）際の物理的な移動距離を厳密に評価します。
ただし、同じ指で異なるキーを連続の間に、反対側の手で打鍵した場合は、SFBのペナルティおよび動的コストは適用されません。

動的コスト $C_{dynamic}$ と静的コスト $C_{static}$ の関係は以下の通りです：

- 同一指の連続打鍵（SFB）の場合、ベースコスト $C_{main}$ は **$C_{main} = C_{static} + C_{dynamic}$** となります。
- それ以外（別指での打鍵や、間に反対の手を挟む場合）は、**$C_{main} = C_{static}$** となり、動的コストは $0$ になります。

### 2-1. 同一キーの連続打鍵 (Double Tap)

全く同じキーを2回連続で打つ場合、指を移動させる必要がないため割引が適用されます。

- $C_{main} = C_{static} \times 0.2$
  （計算上は $C_{dynamic} = -C_{static} \times 0.8$ として加算されます）

### 2-2. 異方性距離 ($D$)

同じ指が別のキーに移動する際、関節の構造上、縦方向（Y軸）の曲げ伸ばしに比べて、横方向（X軸）の開きは筋肉の負担が大きくなります。この特性を反映し、**横方向の移動距離を 1.5倍** にして斜辺（移動距離）を計算します。

- $D = \sqrt{(\Delta X \times 1.5)^2 + \Delta Y^2}$

### 2-3. 非線形疲労ペナルティと最終動的コスト

指を遠くに飛ばすジャンプ（例：上段から下段への跳躍など）は、短い移動の単純な足し算よりも指数関数的に疲労が溜まります。疲労距離は $D^{1.2}$ となります。

最終的な動的コスト $C_{dynamic}$ は以下の数式で算出され、静的コストに加算されます：
$$C_{dynamic} = D^{1.2} \times W_f \times S_{dynamic}$$

- **$W_f$**: 移動先キーを担当する指の基礎重み
- **$S_{dynamic}$**: 動的スケール係数 ($10.0$)

## 3. その他の特徴・アーキテクチャ

### 3-1. 30キー完全対称マトリクスのネイティブ生成

左右で指の並び順が逆転していることによるインデックスのバグを防ぐため、**左右合計30キーのすべての組み合わせのコスト行列をネイティブに生成**します。これにより、右手・左手ともに正確な解剖学的距離計算を保証します。

### 3-2. DP（動的計画法）との統合による文脈評価

「静的コスト」＋「動的コスト」を基礎コスト ($C_{main}$) とし、DPのループ処理内で以下の文脈ベースのペナルティ ($P$) とボーナス ($B$) が加算・減算され、最終的なコスト $C_{total}$ となります。
$$C_{total} = C_{main} + \sum P - \sum B$$

- **SFBペナルティ ($P_{SFB}$)**: 同じ指の連続使用に対する文脈的なペナルティ。段差と指の弱さを加味して算出されます。
  - $P_{SFB} = (B_{SFB} + P_{dist}) \times M_{weak}$
  - 基本ペナルティ $B_{SFB} = 80$
  - 段差ペナルティ $P_{dist} = |\Delta Y_{row}| \times 10$
  - 指の弱さ係数 $M_{weak} =$ 小指・薬指の場合は $1.5$、中指・人差し指の場合は $1.0$
- **シザーズ・ペナルティ ($P_{scissor} = 50$)**: 同じ手の隣り合う指が大きく段を跨ぐ不自然な動き
- **段越えジャンプ ($P_{jump} = 30$)**: 同じ手で2段離れたキー（上段⇔下段）を打鍵する際のペナルティ
- **ロール・ボーナス ($B_{roll}$)**: 指が外側から内側へと流れるような自然なアルペジオへの報酬 (Inward: $5$, Outward: $2$)
- **交互打鍵ボーナス ($B_{alt} = 3$)**: 左右の手を交互に使うことによるリズムボーナス
