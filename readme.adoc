== 緒言
* Autohotkey v2のスクリプト
* 「Space」などを修飾キー(他キーとの同時押しで特殊な操作や文字入力が可能)として動作
** スペースキーダウンから200ms未満（スクリプト設定による）のアップで本来のキーを入力、それ以上で何もしないので修飾キーとして扱える
** キーを押しながら他のキーを押すことで、設定された動作を行う
* 機能の無効化も含めたカスタマイズを推奨
** スクリプトは試行錯誤中で、多機能すぎる→設定は決定版というよりも、サンプルくらいに考えてほしい
** 特殊なキーボード、キー位置が微妙にずれている複数のキーボードを考慮している→複数のキーに同じ機能を割り当てている
** スクリプトをカスタマイズすれば、DvorakやColemak、オリジナルキー配列も可能となる
** 日本語キーボード向け作っているので、USキーボード向けには改変すべきだが、「Space」を修飾キーとして使う機能はむしろ、キーの少ないUSキーボード向けかもしれない
* スクリプトを書き換えれば、IMEがOn/Off状態ごとキーを指定可能
* 「Caps Lock」「ひらがな」は、ahkでの動作が不安定のため、動作を設定する場合はレジストリでScanCodeを書き換え、F13、F14を割り当てておくこと
** レジストリを書き換えなければ、ahkファイルのF13,F14に関する設定は無視される 
* 誤動作発生の可能性があり
** 動作環境依存で誤動作の発生頻度が異なる
*** 通信環境によって伝送遅延があるので長押しタイミングが判定が狂うことがある(長押しシフトはシビア←center_shift.ahkでは未対応)
** キーリピートの開始を遅く（表示までの待ち時間を長く）し、キーリピートを遅く（表示の間隔を遅く）すると改善することがある

=== 用語
レイヤー::
キーに押下することで標準外の文字入力やコマンド発行がなされるキー配列

修飾キー::
ShiftやCtrlと同様に、他のキーの同時押しで特殊な動作が行われるキー +
修飾キーを押している間、レイヤーが切り替わる

== saas.ahk
=== 概要
スペース長押しの同時押しでシフト押下と同じ効果がある +
キー配列の動的切り替え（配列スイッチャー）機能を搭載し、大西配列やColemakなどに変更可能。 []の中にある修飾キーを長押している間、レイヤー切り替え。

=== 配列切り替え
マウス操作不要でキー配列を変更可能。変更時にOSDで通知。 

* Win + q : Qwerty配列
* Win + o : 大西配列 (Oonishi)
* Win + c : Colemak配列

=== キーロガー (KeyLogger)
タイピング統計を収集し、3キーシーケンス（トリグラム）の出現頻度と打鍵間隔を記録します。
各配列の効率分析や、自身のタイピング傾向の把握に活用できます。

* Win + . : キーログの有効/無効を切り替え
* 統計データは `log.txt` に保存されます。

=== IME インジケーター (Dot Indicator)
マウスカーソル付近に現在の IME 状態を小さなドットで表示します。
日本語入力が ON の間、カーソルに追従して表示されます。
* Win + , : インジケーターの表示/非表示を切り替え

=== その他機能
* **サスペンド** : Win + Alt + Enter でスクリプトの一時停止
* **マウス速度制御**: Win + Up/Down でシステムのマウスカーソル速度を変更
* **IME制御**:
** F14 / 変換 で IME トグル
** Shift + 全角 で 英数
