== 緒言
* AutoHotkey v2 用のキーカスタマイズスクリプトです。
* **「Space」キーなどのモディファイア化**:
** 単押し（タップ）では通常の Space として動作し、他キーとの組み合わせでは修飾キー（レイヤー切り替え）として機能します。
** 短押し判定のしきい値（デフォルト200ms）などはスクリプト内で調整可能です。
* **高いカスタマイズ性**:
** 各機能の有効/無効化や、詳細な設定変更を推奨します。
** 多機能かつ実験的な要素も含まれているため、自身の環境に合わせた「ベースサンプル」としての利用を想定しています。
** Dvorak、Colemak、オリジナル配列など、多種多様なキーレイアウトに柔軟に対応可能です。
* **日本語環境への最適化**:
** JIS配列キーボードでの利用を前提としていますが、キー数の少ない US キーボード等への応用も効果的です。
** 「Caps Lock」や「ひらがな/カタカナ」キーの挙動を安定させるため、レジストリ等でスキャンコードを F13, F14 等に書き換えて運用することを推奨します。

* ShiftでCapsLock-Offできる環境以外の動作は不定（以下の設定を推奨）

== sands.ahk
=== 概要
* **スペース・シフト**: スペースバーの長押しを通常の Shift キーと同じように扱えます。
* **配列スイッチャー**: キー配列を動的に切り替え可能。大西配列や Colemak などへ瞬時に変更できます。
* **レイヤー機能**: 指定された修飾キー（[ ] で示されるキー）を押し下げている間、キーマップが対応するレイヤーに切り替わります。

=== 配列切り替え
キー配列を変更可能。

* [F13] + [Win] + [q] : Qwerty配列
* [F13] + [Win] + [o] : 大西配列 (Oonishi)
* [F13] + [Win] + [c] : Colemak配列

=== キーロガー (KeyLogger)
タイピングの統計（3キーシーケンス（トリグラム）の出現頻度と打鍵間隔）を記録します。
各配列の効率分析や、自身のタイピング傾向の把握に活用できます。

* **セキュリティ配慮**: パスワード等の入力を避けるため、**IME ON（日本語入力時）のみ**動作するように設計されています。
* **操作**: [Win] + [.] で機能の ON/OFF を切り替え可能です。
* **データ保存**: 統計結果は `log.txt` に出力されます。

=== IME インジケーター (Dot Indicator)
現在の IME 状態を視覚化します。日本語入力が ON の間、マウスカーソルに追従する小さなドットを表示します。

* **操作**: [Win] + [,] でインジケーターの表示/非表示を切り替え可能です。

=== その他機能
* **サスペンド** : [F13] + [Alt] + [Enter] でスクリプトの一時停止
* **マウス速度制御**: [Win] + [Up/Down] でシステムのマウスカーソル速度を変更
* **IME制御**:
** [F14] / [変換] で IME トグル
** [Shift] + [全角] で 英数
* **ヘルプ** : [F13] + [Win] + [h]で ヘルプを表示
